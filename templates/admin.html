Agents

Each agent can connect to one or more MCP servers — all of their tools are exposed to the specialist. Choose JWT forward for BTP-hosted servers that trust this app's XSUAA (HTTPS on *.hana.ondemand.com; the user's JWT is forwarded on every request), OAuth2 (per-user) for servers with their own authorization server (each user signs in once; tokens are stored per user), or None (public) for public MCP servers that need no authentication.

Skills

Reusable instruction sets that can be attached to agents. The skill's description tells the agent when to use it; the full content is loaded on demand via a load_skill tool, so it doesn't inflate every request. Attach skills to an agent from the agent's edit dialog.

Workflows

A workflow runs several agents in a declared order as one background job. Its fan-out step returns the work items; each item enters only the branches that step selected for it, and the remaining main-line steps then run as the join.

LLM model

Active model used by the orchestrator and all specialists. The list is read live from your SAP AI Core (the models you have deployed in the Generative AI Hub). Changing this saves and reloads the registry immediately. Names containing claude or starting with anthropic are routed to the Bedrock proxy; everything else uses the OpenAI-compatible proxy.
